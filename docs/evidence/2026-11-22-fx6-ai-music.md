## Codex review fixes (round 1)

1. Live is checked again inside the heavy-job lock right before the child starts (and while it runs).
2. A stored track JSON is read field by field with type and range checks; `pack`, `credit`, `source` and every other
   key are dropped. A file without its `generated` block is refused. The render record is built in code
   (`record()`), and the clipper picks the record by the branch that found the track, not by keys on it.
3. The worker takes plain names for out, result and work, all inside the job file's folder, and checks every field
   before importing torch.
4. Timeout, live stop and every failure remove the part WAV, the job, the result and the work folder (in
   `music_gen` too, since a killed worker cannot clean up); the worker uses try/finally for its work folder.
5. Stored tracks are reused with the tick alone; only new ones need the runtime.
6. Runtime path moved from the profile to the `aiRuntime` setting with a folder picker.
